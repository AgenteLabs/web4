The stack

Nine layers, one question each. This table is rendered from the stack.json copy this site serves (contract web4/1, generated 2026-09-28); where the page and the file disagree, the file is the truth. The map’s home is FlashyLabs/web4, and the era it maps is Web 4. The aao repository on it is the specification an Agentic Autonomous Organization is written against.

Own the open protocols through which agents discover, identify, authorize, trust, transact with and audit one another — not the agents.
