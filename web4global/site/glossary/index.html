Glossary

A glossary of links, not of definitions. One owner per term across the estate; a term owned elsewhere is linked with the owner’s anchor and one line saying what you will find there.

TermWhere it is definedWhat you will find
Web 4Web 4 gda.groupThe era: four conditions that hold at once. Defined by GDA Group; this community builds for it and never restates it.
agentic internetagentic internet flashyos.comThe infrastructure: six verbs, one open protocol each, and the record a stranger re-verifies.
Agentic Autonomous OrganizationAgentic Autonomous Organization flashyos.comThe category Web4 Global is an instance of: operating work done by a persistent fleet of agents under human governance.
AAO stackAAO stack flashyos.comWhat ships, layer by layer, and what is live today.
agentic networkthe agentic network flashyos.comWhat FlashyOS is; the mesh this community runs on.
agentic webagentic web flashyos.comThe surface layer: pages, APIs and well-known files written for an agent as the reader that acts.
agentic mesh networkagentic mesh network flashyos.comThe agentic internet seen as a network of organisations' agents, governed at the mesh layer.
financial layer of the agentic internetthe financial layer of the agentic internet flashy.financialWhat the phrase means and what a wallet on the agentic internet owes its holder.
Web 4 developerweb4.global owned hereA Web 4 developer builds software that lets agents discover, identify, authorize, trust, transact with and audit one another across organisations, on open protocols, with a human accountable for every agent they ship.
agentic developerweb4.global owned hereAn agentic developer is a developer whose primary users are software agents: they publish machine-readable surfaces, declare what their agents may do, and build so that another organisation's agent can verify every claim without asking.
Web 4 communityweb4.global owned hereA Web 4 community is a group of developers who build for Web 4 together in public: in chapters with a named lead, at build nights that are recorded, and as an organisation whose agents and rules strangers can read.
Web 4 chapterweb4.global owned hereA Web 4 chapter is a city-based group of agentic developers that is itself an organisation on the mesh: its own domain, charter and accountable lead, a consented membership edge to Web4 Global, and a monthly witnessed build night.
build nightweb4.global owned hereA build night is a chapter's monthly working session: developers ship something for Web 4 in one evening, the chapter's agent records it as an observance with a public evidence URL, a second party witnesses it, and the lead consecrates it.
Web 4 hackathonweb4.global owned hereA Web 4 hackathon is a build competition run through the mesh itself: intents are filed, work is offered and settled, and receipts are sealed, so the proof of what was built is on the estate's record rather than in a press release.
Web4 Globalweb4.global owned hereWeb4 Global is the global community of agentic developers: city chapters, build nights, a builder track and answers, run as an accountable organisation on the FlashyOS mesh with a public charter, directory and calendar.
charterweb4.globalThis organisation's AAO charter, served where a checker reads it: eight roles, each with a purpose, a measure and a human-approval floor.
handshakeweb4.globalThe flashyos/1 document that lets a stranger's agent discover this organisation and the capabilities its roles carry.
conformance levelweb4.globalL1 discoverable, L2 chartered, L3 accountable. Only L3 carries the mark, and it is read from the register.
directory/1web4.globalThe organisation, its agents and its chapters as nodes and consented edges, with visibility and expiry on every row.
ritual/1web4.globalThe calendar: liturgies and observances. Agents observe, a second party witnesses, a person consecrates.
the consent ruleweb4.globalAgents suggest; humans consent. No edge is countersigned and no observance consecrated by a machine.
the surveyweb4.globalHow the chapter count is measured: fetched, classified, and never computed over what could not be read.
