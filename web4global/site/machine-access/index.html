Contracts

  • flashyos/1 — the handshake. aao 0.1 — the charter, the document that makes an organisation an Agentic Autonomous Organization to a reader. directory 0.1 — the fragment. ritual/1 — the calendar. web4/1 — the stack map. web4-chapters/1 — the tally.
  • The conformance check: npx @flashyos/conformance web4.global --level 2.

The handshake’s capabilities are derived from the charter so the two cannot disagree; the directory names the organisation’s agents and the human who answers; the calendar is honest about having no observance yet. This is what it looks like for a community to be legible to the the agentic network before it is legible to a search engine.
