Answers

One sentence first, under forty words, then the account. A term another property owns is linked to its owner on the line it is said; where a definition below says AAO, it means an Agentic Autonomous Organization as FlashyOS defines it.

What is a Web 4 developer?

A Web 4 developer builds software that lets agents discover, identify, authorize, trust, transact with and audit one another across organisations, on open protocols, with a human accountable for every agent they ship.

owned term · Web 4 developer

What is an agentic developer?

An agentic developer is a developer whose primary users are software agents: they publish machine-readable surfaces, declare what their agents may do, and build so that another organisation's agent can verify every claim without asking.

owned term · agentic developer

What is a Web 4 community?

A Web 4 community is a group of developers who build for Web 4 together in public: in chapters with a named lead, at build nights that are recorded, and as an organisation whose agents and rules strangers can read.

owned term · Web 4 community

What is Web4 Global?

Web4 Global is the global community of agentic developers: city chapters, build nights, a builder track and answers, run as an accountable organisation on the FlashyOS mesh with a public charter, directory and calendar.

owned term · Web4 Global

What is a Web 4 chapter?

A Web 4 chapter is a city-based group of agentic developers that is itself an organisation on the mesh: its own domain, charter and accountable lead, a consented membership edge to Web4 Global, and a monthly witnessed build night.

owned term · Web 4 chapter

How do I build on Web 4?

Pick the layer of the stack your work answers, publish a handshake and a charter on your own domain, run the conformance check until it exits zero, and ship work that settles on the mesh with a re-verifiable record.

How do I start a Web4 Global chapter?

Name a lead, pick a city and a monthly build night, run the chapter kit on a domain you control, reach conformance level two there, adopt the code of conduct, and file the membership edge for a steward to countersign.

What is a build night?

A build night is a chapter’s monthly working session: developers ship something for Web 4 in one evening, the chapter’s agent records it with public evidence, a second party witnesses it, and the lead consecrates it.

owned term · build night

How does a developer reach conformance level two?

Serve a valid flashyos/1 handshake at /.well-known/flashyos.json and an AAO charter at /.well-known/flashyos-charter.json on your own domain that passes every static question, then run npx @flashyos/conformance with --level 2 against the live domain until it exits zero.

What is a Web 4 hackathon?

A Web 4 hackathon is a build competition run through the mesh: intents are filed, work is offered and settled, and receipts are sealed, so the proof of what was built is a record, not a press release.

owned term · Web 4 hackathon
