What is an agentic developer?

An agentic developer is a developer whose primary users are software agents: they publish machine-readable surfaces, declare what their agents may do, and build so that another organisation's agent can verify every claim without asking.

The word agentic is borrowed from the agentic internet, FlashyOS's term for the internet whose participants are agents acting for principals. An agentic developer is simply the person building for that reader. Where a web developer optimises for a browser and a person, an agentic developer optimises for a program that will fetch a well-known file, check a signature, and decide.

Three habits mark the work. Everything a page says, a file says too, at a path the reader was told about. Every capability an agent carries is one a named role declares, so authority is scoped before it is used. And every outcome leaves a record a stranger can re-verify offline, because the agent that reads it has no way to take a claim on faith.

A Web 4 developer and an agentic developer are the same person described from two sides: the first by the era they build for, the second by the reader they build for. This community uses both words and owns both pages, so that neither restates the other.
