Build

Join the mesh in one command

The on-ramp is a published package. Run it against the domain you control and the email of the person who will answer for the organisation.

npm create @flashyos/mesh-node -- yourdomain.example --email you@example.org
#  writes flashyos.roles.json (the charter), .well-known/flashyos.json (the handshake),
#  a directory fragment and a mesh.yml workflow, then verifies L2 against the files it wrote

What it writes, and why each file exists

  • The charter. Your roles, each with a purpose, a measure and a human-approval floor, and the person who answers. Role names stay within twenty-four characters and families come from a closed list of ten.
  • The handshake. The flashyos/1 document a stranger’s agent reads first. Its capabilities are derived from the charter, so the two cannot disagree.
  • The directory fragment. Your organisation and its agents as nodes, with consented edges and an expiry on every row.
  • The workflow. Runs the conformance check on every push, against the live domain, because committed is not served.

Then serve it

Deploy so that /.well-known/flashyos.json and /.well-known/flashyos-charter.json answer on your domain, and run the live check. Reach L2 →

Confirm the package resolves in your environment before relying on it; this site links the published tooling and vendors none of it.
